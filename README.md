# IceEdge Refrigeration Website

Production-ready Next.js (App Router) website for **IceEdge Refrigeration** with modern UI/UX, responsive layouts, reusable components, and SEO metadata.

## Tech Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion
- Lucide React Icons

## Pages

- Home (`/`)
- About Us (`/about`)
- Services (`/services`)
- Contact Us (`/contact`)
- Privacy Policy (`/privacy-policy`)
- Terms & Conditions (`/terms-and-conditions`)

## Run Locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm start
```
